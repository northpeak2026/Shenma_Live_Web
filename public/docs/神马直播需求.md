# 有料

## 1. 有料模块概述

### 1.1 有料模块定位

有料模块用于展示体育赛事相关的专家推荐方案，支持用户浏览方案、查看专家战绩、购买收费方案、解锁推荐内容及查看结算结果。

有料模块需要与赛事、直播及用户个人主页打通，确保用户可以从不同业务入口查看同一份有料方案。

### 1.2 全局导航

在 Web Header 导航栏中新增【有料】入口，位置在【赛事】之后。点击后进入有料首页。

### 1.3 核心页面

1. 有料首页。
2. 专家排行榜。
3. 有料详情页。
4. 专家个人主页中的有料内容。
5. 赛事详情页中的有料 Tab。
6. 直播详情页中的有料 Tab。

## 2. 有料首页

### 2.1 页面布局

有料首页采用左右双栏布局。左侧为主要内容区域，展示有料列表。右侧为辅助信息区域，从上到下依次展示专家排行榜、焦点赛事。

### 2.2 有料列表

有料列表支持以下筛选条件：

| 筛选条件 | 选项 | 规则 |
| --- | --- | --- |
| 赛事分类 | 足球、篮球 | 根据赛事类型展示适用的盘口 |
| 盘口分类 | 胜平负、胜负、让球、大小球 | 胜平负适用于足球，胜负适用于篮球 |
| 付费类型 | 全部、钻石、金币、免费 | 可与赛事、盘口分类组合 |

#### 有料卡片字段

每张卡片至少展示：

- 专家头像。
- 专家昵称。
- 专家胜率。
- 专家近期战绩，例如近 10 场中 9 场。
- 专家当前连红次数。
- 有料标题。
- 关联赛事信息。
- 盘口类型。
- 发布时间。
- 收费方式。
- 收费价格。
- 已结算方案的结果标识(有料首页不会展示，专家个人中心会展示此字段)。

| 点击对象 | 跳转目标 |
| --- | --- |
| 有料卡片 | 对应有料详情页 |
| 专家头像或昵称 | 专家个人主页，默认选中【有料】Tab |

### 2.3 专家排行榜

右侧展示胜率榜、连红榜。默认展示胜率榜。每个榜单支持分页展示。

排行榜字段包括：排名、专家头像、专家昵称、对应榜单指标。前三名可以通过排名颜色或图标适度突出。

#### 排行榜统计规则

统一使用最近 7 天的数据。

| 榜单 | 统计条件 | 排序指标 |
| --- | --- | --- |
| 胜率榜 | 最近 7 天发布的方案数量大于 5，胜率大于 55% | 胜率 |
| 连红榜 | 最近 7 天发布的方案数量大于 2，且近期连红次数大于 2 | 连红次数 |

### 2.4 焦点赛事

焦点赛事展示在专家排行榜下方。只展示同时满足以下条件的赛事：

1. 该赛事关联了有料方案。
2. 赛事状态为未开赛或进行中。

赛事卡片展示：

- 联赛名称。
- 开赛时间或比赛进行时间。
- 主队 Logo。
- 主队名称。
- 客队 Logo。
- 客队名称。
- 关联的有料方案数量。

点击赛事卡片后，进入该赛事对应的有料列表。该列表只能展示当前赛事关联的有料方案。

## 3. 有料详情页

### 3.1 页面布局

采用适合 Web 的左右双栏结构。

| 区域 | 展示内容 |
| --- | --- |
| 左侧有料主体 | 赛事信息、盘口信息、专家推荐方向、有料正文、结算结果 |
| 右侧辅助信息 | 专家资料、专家近期战绩、购买信息、其他相关信息 |

### 3.2 专家信息

展示专家头像、专家昵称、关注按钮、胜率、近期战绩、连红次数。

点击专家信息进入专家个人主页，默认选中【有料】Tab。

### 3.3 有料基础信息

展示有料标题、发布时间、关联赛事、盘口类型、盘口数值、赔率。

### 3.4 专家推荐方向

#### 未购买的收费方案

- 展示该盘口的全部选项。
- 展示对应数值及赔率。
- 不高亮任何推荐选项。
- 不得通过颜色、样式、文案、排序或其他数据提前暴露推荐方向。

#### 已购买的收费方案

- 明确高亮专家实际推荐的盘口选项。
- 用户应当能够快速识别推荐方向。

#### 免费方案

- 无需购买。
- 直接展示推荐方向和完整正文。

### 3.5 有料正文

#### 未购买的收费方案

- 正文区域使用毛玻璃或模糊遮罩效果。
- 展示解锁提示。
- 展示购买截止倒计时。
- 不得通过遮罩之外的其他信息泄露推荐正文。

#### 已购买的收费方案

- 移除正文遮罩。
- 展示完整正文。
- 同步高亮专家推荐方向。

#### 免费方案

直接展示完整正文。

### 3.6 购买区域

展示当前方案价格、支付资产类型、用户对应资产余额、立即支付按钮。支持的支付资产为金币、钻石。

支付规则：

1. 根据方案配置使用对应资产。
2. 余额不足时，明确提示用户。
3. 购买成功后更新用户资产余额。
4. 购买成功后立即解锁方案，无需刷新页面。
5. 购买成功后同步更新该方案的购买状态。
6. 用户在其他入口打开同一方案时，应当继续保持已解锁状态。

### 3.7 购买截止时间

| 状态 | 展示与行为 |
| --- | --- |
| 尚未截止 | 展示剩余购买时间，倒计时正常更新 |
| 已截止 | 停止倒计时，展示【已截止】状态，未购买用户不可继续购买；已购买用户仍可以正常查看完整内容 |

## 4. 有料结算结果

### 4.1 结算状态

支持以下五种结算结果：

| 结果 | 展示要求 |
| --- | --- |
| 赢 | 明确展示成功状态 |
| 赢半 | 明确展示部分获胜状态 |
| 走水 | 使用独立的中性状态 |
| 输半 | 明确展示部分失利状态 |
| 输 | 明确展示失败状态 |

> 关键限制：不能将所有结果简单归纳为成功和失败两种状态。

### 4.2 专家主页列表展示

已结算方案在专家有料列表卡片中展示对应的结算结果标签。

### 4.3 详情页展示

详情页需要明确体现：

- 专家实际推荐的方向。
- 该推荐方向对应的最终结算结果。

对于已购买或免费的方案，可以正常展示推荐方向及结算状态。

## 5. 专家个人主页与主播个人主页融合

### 5.1 基本原则

Web 项目已经存在主播个人主页。本次不单独开发一套完全独立的专家个人主页，而是将主播和有料专家的个人主页进行融合。同一个用户可能同时具有主播身份和专家身份。

### 5.2 身份展示规则

| 用户身份 | 个人主页展示 |
| --- | --- |
| 仅主播 | 展示直播相关内容 |
| 仅专家 | 展示有料相关内容 |
| 同时是主播和专家 | 同时展示直播和有料两个 Tab |

### 5.3 直播 Tab

保留原有主播个人主页功能，包括：

- 直播预告。
- 直播回放。
- 原有主播相关信息。

### 5.4 有料 Tab

展示：

- 专家战绩数据。
- 胜率。
- 回报率。
- 连红次数。
- 专家发布的有料方案列表。

点击方案进入对应有料详情页。

### 5.5 入口联动

| 入口 | 默认选中 |
| --- | --- |
| 从直播模块点击主播头像进入个人主页 | 【直播】Tab |
| 从有料模块点击专家头像进入个人主页 | 【有料】Tab |

用户可以在个人主页中自由切换两个 Tab。

## 6. 赛事详情页新增有料 Tab

### 6.1 Tab 位置

在赛事详情页现有【阵容】Tab 后新增【有料】Tab。保留其他现有 Tab 和功能，不调整其他 Tab 的顺序。

### 6.2 数据展示

点击【有料】Tab 后，展示当前赛事关联的全部有料方案。

方案卡片复用有料模块的业务逻辑。

### 6.3 页面跳转

| 点击对象 | 跳转与行为 |
| --- | --- |
| 有料卡片 | 进入对应有料详情页，保留原有购买、解锁、截止时间和结算逻辑 |
| 专家头像或昵称 | 进入对应专家个人主页，默认选中【有料】Tab |

### 6.4 空状态

即使当前赛事没有关联有料，也保留【有料】Tab。展示合适的空状态，例如：【暂无相关有料】。

## 7. 直播详情页新增有料 Tab

### 7.1 Tab 位置

在直播详情页现有【赛况】Tab 后新增【有料】Tab。

### 7.2 Tab 展示条件

直播间的有料数据来源于当前直播绑定的赛事。只有同时满足以下条件时，才展示【有料】Tab：

1. 当前直播绑定了赛事。
2. 该赛事存在关联的有料方案。

如果直播没有绑定赛事，或者绑定的赛事没有关联有料方案，则不展示【有料】Tab。其他 Tab 正常展示。

### 7.3 数据展示

点击【有料】Tab 后，展示当前绑定赛事关联的全部有料方案。

### 7.4 页面跳转

| 点击对象 | 跳转目标 |
| --- | --- |
| 有料卡片 | 对应有料详情页 |
| 专家头像或昵称 | 专家个人主页，默认选中【有料】Tab |
